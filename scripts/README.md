# Maintenance scripts

- `complete-web-check`: static integration check for the retained browser and WebX source.
- `complete-web-actual-runtime`: actual-runtime qualification harness for future rebuild work.
- `live-web-acceptance.mjs`: live capability acceptance harness.
- `pi-package-stage`: stages the Pi extension package.
- `pi-package-cutover`: activates a staged Pi extension package.

The source is not currently installed. Do not run cutover scripts until the unified installation path has been reviewed.
